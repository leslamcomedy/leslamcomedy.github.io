# 推荐资料

欢迎演员、俱乐部和喜剧爱好者推荐公开的演出、播客、书或创作手册。

发来**资料标题和原始链接**就可以了。也可以加一句推荐理由，或注明希望展示的演员名、俱乐部名。如果同一份资料在不同平台都能打开，欢迎把链接一起发来。

- **乐咔群友**可以把链接发到俱乐部微信群，或私发给主理人。
- **其他城市的朋友**可以通过 [Instagram 私信乐咔](https://www.instagram.com/leslamcomedy/)，也可以在小红书搜「慕尼黑乐咔喜剧」（小红书号 `6381249812`）。

已有条目的链接失效、来源有误或需要更新，也欢迎通过这两个渠道告诉我们。
