# 播客

分两类。整档都值得听的，推荐整档听。某一期特别好的，单独列出来。

链接都是小宇宙。装了小宇宙 App 的话，会直接在 App 里打开。

## 整档推荐

### 高脚凳对谈

韩大狗做的。每期请一位脱口秀演员，聊专场背后的事：名字怎么来的、内容怎么排、巡演里怎么改。整档都是脱口秀技巧。

👉 [在小宇宙打开](https://www.xiaoyuzhoufm.com/podcast/65db705c145b3259fbfa5d63)

### 大风天台

宁家宇和大风天喜剧做的。采访有专场的脱口秀演员，聊他们的演出和专场。

👉 [在小宇宙打开](https://www.xiaoyuzhoufm.com/podcast/6221c4aaf851ffbdabd3d574)
