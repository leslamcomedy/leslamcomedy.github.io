# 二维马：猜拳

单立人原创喜剧大赛 2021 夏。视频在优酷，搜索「二维马 猜拳 单立人原创喜剧大赛」。

## 逐字稿

大家好，我是二维码。
我是一个比较好信儿的人，就是我受不了别人挑衅我或者反问我。
上次我讲到这儿的时候，蝶衣观众是吗？
看着不像，我特别开心，这就是我的观众，什么样人找什么样人吗？
我这辈子遇到过的最不相信我的人应该就是我的母亲。
因为东北的父母他不太会用陈述句。

我的生活中总听到这样的对白说，你吃不了就别吃了呗，那剩一口能咋的？
朋友们，我能剩饭吗？
饭这个东西，在我心中就是有一口吃一口。
我的信条是这样的，我嘴里这口只要能咽下去，我就还能吃一口。

我以前不觉得我的性格有什么问题，直到我高中的时候，我们班男生之间开始流行一种非常让人喜闻乐见的体育活动，叫做猜拳抽嘴巴子。
你们大体上应该都抽过人嘴巴子，对吧？
你们就抽就是抡圆了啪反手就在我们这，这都属于基本操作。
你们见过有人抽嘴巴子是助跑的吗？

那个人笔直的冲过来，在靠近他的击打物体的时候停止，用线速度转化成角速度带动转体，用它动力臂力最外沿，狠狠的抽在别人脸上。
这个人是我们班物理课代表。

他让我明白了人是会旋转的，同时他也打丢了自己的物理课代表的职位，用一次货真价实的物理攻击。
后来他们被我们称为他被我们称为ADC，就开始这个时候这个游戏只有两个傻子玩，很快的就出现了人传人的现象。
原理也很简单，谁没有几个仇人呢？
而且你很难停止下来，因为你总觉得抽出去的嘴巴子没有挨在脸上的疼。
这一帮傻子天天抽嘴巴子。
下午放学的时候，我们班男生就有一半人的脸是浮肿的。
今天比赛要稍微激烈一点，就都是浮肿的。
我从来不玩，但是我也没有因此而显得格格不入。

经常有人过来，来，咱们猜拳抽嘴巴。
你今天可不能再玩了。

我一直与这个游戏井水不犯河水，直到有一天我的同桌坐在我旁边开口挑衅我，他都不是问我说你是不是怕挨打？
他问我你是不是不会猜拳？
我说什么？
把手给我掏出来，我们已经要开始了。

一个下午过去了，我发现我可能是不会猜拳。
就具体表现为在这项游戏当中，我用到手和脸的比例近乎是1比1，我每用到一次手就要用到一次脸。
我可能是不会猜拳，但是我非常刚，我很有毅力，他很有耐力，我的毅力和他的耐力斗的是旗鼓相当。
这种情况下就是怎么说呢？
我越挫越勇，他越跑越快。

我们两个的行为很快引起了其他傻子的围观，一帮人把我们两个围在了当中，他们看却不敢说话，因为我的战术他们看不懂。
我就像一个超级巨星一样，划时代的改变了比赛的规则，还是ADCE最后张嘴了，他说你这个打法好啊，你这个打法它不伤手。
气死我了，那天回家的时候，他终于被我打光了勇气，他认怂了，对我说出了那一句，今天你可不能再玩了。
今天会，然后我就发现另一个问题，就是你别看我的脸是这个样子，他也能更重。
你看因为我妈就看出来了，晚上回家吃饭。
然后我妈看着我说你以后吃饭别老用一边嚼。
谢谢大家，我是28。
